Self-hosted [Webtor](https://webtor.io) on a free Hugging Face Space.

Paste a magnet, pick a file, stream or download from any browser. Stremio addon URL is on the profile page after it boots.

This is a BitTorrent gateway. Only use it for content you have the right to share. Hugging Face may sleep or stop Spaces that violate their terms.
